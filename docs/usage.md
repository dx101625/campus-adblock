# 按自己的习惯使用

模块支持胖乖生活、智趣校园独立App。胖乖的设备自动流程可选择强度，付款始终由用户确认。

## 首页

顶部统一卡片的上半行显示模块激活状态，点击可查看框架版本、目标应用作用域并重新检测；下半行显示当前使用方式，点击进入使用习惯。绿色已激活标记来自框架服务的当前连接，历史加载时间另列于两个应用卡片中。详见[激活状态说明](activation.md)。

首页上方显示普通打开胖乖时的实际使用方式，点击卡片可调整。它同时考虑全局偏好、默认设备档案和“仅设备入口”，不会为展示而改动设置。

“我的应用”显示从系统读取的真实图标、当前安装版本和上次模块加载时间。时间表示历史记录，不表示目标App当前仍在运行。点击应用卡片进入对应设置；未安装时显示文字占位。大字体下两张卡片会自动纵向排列。

常用设备区可管理设备档案；已选择默认档案时保留按档案打开的入口。运行记录显示最近的处理结果，并提供兼容性体检入口。首页不再重复展示整组版本信息。

## 设置入口

功能页按类别展示7个入口，点击进入二级设置。顶部返回箭头与系统返回键可回到分类页，设置即时保存。

| 入口 | 内容 |
| --- | --- |
| 使用习惯 | 三种模式、普通打开或仅设备入口 |
| 设备码与常用设备 | 图片转设备码、收藏与默认设备码 |
| 胖乖生活 / 智趣校园 | 各自广告设置与设备偏好 |
| 广告与外跳 | 防摇一摇、广告外跳开关、允许打开的应用 |
| 自动流程保护 | 连续失败暂停、报价变化提醒 |
| 配置与诊断 | 备份恢复、日志、体检和运行记录 |

界面主题、底栏材质、动态效果与触感移到“关于 → 右上角设置”；组件说明和许可在“关于 → 引用与许可”。

选项行显示当前值，点击展开紧凑玻璃面板。浅蓝底、蓝色文字与勾号共同表示选中，点选后收起；点右上角关闭、面板外或系统返回可取消。其他二级弹层也复用同一材质。Android12及以上使用实时背景模糊与边缘折射；较旧系统或选择清晰轻量、高对比度时使用清晰实色。

## 图片转设备码

在“功能 → 设备码与常用设备”点击“图片转设备码”，从系统文件选择器挑选清晰二维码图片。识别仅在本机完成。

结果可直接复制，或点击“设为默认设备码”保存；不会自动建立收藏或打开目标App。取消、关闭结果和识别失败均保留原配置。

## 三种使用方式

| 模式 | 模块操作 | 用户操作 |
| --- | --- | --- |
| 仅去广告 | 清理已匹配的广告、开屏等待和广告外跳 | 正常扫码、选设备、选档位、选择优惠与支付 |
| 设备页 | 识别默认设备码，按偏好预选后停在设备页 | 核对、调整参数，再手动继续 |
| 订单预览 | 识别设备、应用偏好并推进到订单预览 | 核对金额与选项，手动付款 |

全局“仅去广告”保证**普通打开App**时不会执行自动识别、预选或推进。主动点击独立设备入口时，按该设备档案的模式使用；未独立设置的项目跟随全局。

在“功能 → 使用习惯”选择。如果喜欢全部自己操作，选择“仅去广告”；如果希望保留普通打开的手动体验，同时偶尔直达某台设备，选择“仅设备入口”，再给相应档案设置模式。

“何时使用自动流程”可选：

- 普通打开：按默认设备及全局/设备偏好处理。
- 仅设备入口：普通打开只去广告；从桌面设备快捷方式或档案按钮打开时，才应用设备档案。

## 常用设备档案

1. 在“功能 → 设备码与常用设备”添加设备码链接，或从系统文件选择器导入清晰的二维码图片。
2. 填写名称，可选分组与设备图标。
3. 需要时单独设置模式、机号、档位、支付、优惠券和积分；“全局”表示继承当前全局值。
4. 点收藏设为默认。长按右侧排序手柄拖动，可调整列表与桌面长按菜单中的优先顺序。
5. 编辑已保存档案，可选择“添加到桌面”。桌面是否接受请求由系统桌面决定；动态长按菜单会展示最多3台靠前设备及普通首页入口。

设备入口只携带本地档案ID，最新设备码与偏好由模块私下读取。重命名会更新入口标签；删除档案会使已有入口失效。删除后短时间内可撤销。删除收藏不会清除当前设备码；清空覆盖值仍需确认。

部分系统首次使用时会询问是否允许模块打开胖乖，或要求开启“创建桌面快捷方式”。按自己的需要在系统界面授权；不支持固定入口的桌面仍可使用模块内入口与支持的长按菜单。

设备入口的偏好保留在该次目标App进程会话中，切到其他App再返回不会突然改成另一种模式；使用其他设备入口或完全退出重开后重新选择。更改全局设置后请完全退出并重启目标App。

## 失败与报价变化

同一设备连续识别失败3次，会暂停该设备的自动直达，保留手动操作。在“自动流程保护 → 暂停状态与报价变化”恢复后重试。暂停开关不会关闭去广告。

报价保护比较同一设备、机号及档位偏好对应的原App报价与时长。首次建立本机参考；价格或时长变化会停在设备页，不自动改变参考。核对后可手动操作，或在模块中确认接受新参考。它不表示已付款或实际消费，也不会查询支付账单。

参考、失败计数、短期放行与运行摘要只存本机，不随配置备份导出。报价参考最多60项，失败记录最多30台设备。

## 广告外跳与例外

页面只保留防摇一摇、广告外跳拦截两个常用开关，以及“允许打开的应用”。需要正常打开某个名单内应用时，在例外列表开启它，再重启目标App。支付应用不在广告拦截名单中。

v1.6.1移除拦截强度和临时放行的界面入口，不迁移或覆盖已有的`g.jump.mode`、`g.jump.allowed`配置；旧的标准或严格规则继续按原值执行，首次使用仍默认标准。旧临时放行记录遵循原来的有效期，最多5分钟自动失效。

## 体检与反馈

“模块已加载”只表示目标进程加载了模块。兼容性体检显示入口安装情况；可选广告SDK不存在不等于全部功能失效。具体成功、失败或暂停原因以最近运行记录为准。

反馈入口复制脱敏诊断并打开GitHub页面，由用户核对后提交。二维码、账号、订单和支付信息不要放入截图或反馈正文。

## 界面偏好

支持应用内跟随系统/浅色/深色、液态玻璃/清晰轻量、动态效果及轻触反馈。界面选择立即预览，不修改手机系统设置；系统关闭动画或触感时，应用遵循系统设置。

快速左右拖动底栏时，玻璃透镜随速度轻微形变，松手后有短促回弹；慢速拖动保持跟手。动态效果关闭或系统动画关闭时，停用弹性动画。

二级页面和玻璃弹层展开时也使用轻微弹簧回弹；帮助问题展开时柔和伸展。动态效果关闭后直接显示，避免反复弹动。
