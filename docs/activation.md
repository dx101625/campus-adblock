# 首页模块激活状态

首页最上方把激活状态与使用方式放在同一张卡片中：上半行查看框架状态，下半行调整普通打开胖乖时的行为。

绿色“模块已激活”来自[libxposed Service](https://github.com/libxposed/service/tree/102.0.0)提供的当前进程服务连接。模块在后台读取框架名称、版本、服务API及作用域，连接断开或重新查询失败时清除对应状态。页面返回前台或手动点击重新检测时会重新读取；不会将激活标记写入配置文件。

“已选2/2个目标应用”表示框架返回的作用域包含胖乖生活与智趣校园，不代表每一项功能已经执行成功。两个应用卡片上的时间仍表示上次加载记录，功能结果查看运行记录及兼容性体检。

未收到服务连接时显示“未连接到LSPosed框架”，点击后可查看启用提示并打开框架管理。旧框架可能没有提供服务接口，单凭未连接不能断言模块一定未启用。

依赖固定为Maven Central已发布的io.github.libxposed:service:102.0.0及其interface依赖。官方主分支文档提到的102.0.1在本轮查询时尚未发布到Maven Central，本项目使用已发布版本。

官方库声明最低API26。本项目保留原有minSdk24设置界面：新Provider通过资源在API24-25禁用，服务客户端只在API26及以上进入隔离桥接类；Android7界面显示状态服务不受支持。Manifest合并保留对应的显式overrideLibrary。API24已在独立Android7模拟器完成原签名APK首装和界面检查，未单独测试API25，也未在Android7真机验证目标App Hook。

新Provider采用Direct Boot aware声明。应用保持默认Application初始化，接收Binder时只使用官方服务缓存；读取用户配置和注册界面监听在用户打开设置页时进行，不在首次解锁前访问凭据保护配置。

本轮原手机实际返回LSPosed 2.2.1、服务API102，两个目标应用均在作用域。框架连接状态与冷启动、深色、字号/旋转、断开/过期回调测试记录见本地验收目录。
