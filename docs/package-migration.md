# 旧包名迁移到 GitHub 账号包名

从 v1.6.3 起，安装包 applicationId 为 `io.github.dx101625.campusadblock`。旧版本为 `com.campus.adblock`。此改动用于满足模块仓库的账号命名空间要求；Java/Kotlin 源码 namespace 仍保留原值，不影响安装包身份。

Android 将两个包名视为两个应用。新版不能直接覆盖旧安装；同一签名也不会自动复制数据。

1. 在旧版打开“功能 → 配置与诊断 → 配置备份与恢复”。如需保留设备码和收藏，开启“备份中包含设备码”，再导出备份。该文件含私人设备信息，勿上传 GitHub。
2. 安装新版，在同一入口选择“导入备份”，核对并恢复。schema 1/2 的旧版备份均可读取。默认不含设备码的备份只迁移一般设置。
3. 框架中关闭旧模块，启用新版，重新勾选胖乖生活与智趣校园作用域。不要同时启用两份模块。
4. 按框架要求重新加载模块或重启设备，并完全退出、重开目标 App。仅看到旧版的历史记录不代表新版已生效。
5. 桌面上的旧设备快捷方式属于旧包名，需在新版重新创建。旧设备码与收藏在成功导入后可继续使用。
6. 核对新版的默认设备、偏好、框架激活状态和运行结果后，再自行决定是否卸载旧版。不要在导出之前卸载或清除旧数据。

失败计数、报价参考、临时跳转允许和历史运行日志不属于配置备份，无需迁移。新版延续 v1.6.2 的单开关行为：开启自动到订单预览，关闭仅去广告；最终付款由用户确认。

首次安装的用户直接安装新版、启用框架作用域并准备设备码即可，不需要以上迁移步骤。
